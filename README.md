# HomeworkFlow

HomeworkFlow 是从 ScoreFlow 中独立整理出来的“作业周统计”应用。它完全本地运行，可以生成带机器身份的纸质周表，回收后批量扫描识别、人工复核，并导出每周 Excel 汇总。

## 已包含

- 直接粘贴“学号 姓名”学生名单，支持空格、多个空格和 Excel 两列复制出的 Tab，保留 `01` 这类前导零学号。
- 网页设置班级、开始日期、结束日期、学科、工作日过滤和份数。
- 一张 A5 对应“一个学科的一周”，每名学生按日期拥有独立 OMR 方框。
- A4 自动拼版，每页两张 A5；奇数张时最后一张自动作为备用表。
- 每张 A5 独立二维码、四角定位点和 JSON manifest。
- 空白、正斜杠、反斜杠、X、涂黑/疑难五类 OMR 核心分类器。
- A4/A5 PDF、PNG、JPG 等扫描件导入，自动拆分、旋转和透视校正。
- SQLite 保存批次、名单快照、表单、原始识别、复核结论和导出记录。
- 疑难项人工复核与批次确认。
- `周汇总`、`缺交明细`、`平台导入` 三工作表 Excel 导出。
- 平台 Excel 模板第一行列名和顺序适配，未知列保持为空。

## 工作流程

1. 粘贴学生名单并生成 PDF 与 manifest。
2. 按 100% / 实际大小打印，周末回收。
3. 在“扫描识别”中导入整张 A4、裁切 A5、照片或 PDF。
4. 在“周批次与人工复核”中处理疑难格。
5. 确认批次后导出 Excel。

同一学科存在多份纸表时，汇总采用“任一份明确为已交即视为已交”的规则；同一表单重复扫描时使用最近一次结果。

## 当前边界

当前 OMR 是规则型识别器，真实手机拍照、阴影、折痕、不同笔迹和低分辨率扫描仍需要用实际样本校准阈值。系统会把无法可靠判断的格子送入人工复核，不会静默猜测。平台适配只依据用户上传模板的第一行列名，不内置或猜测第三方平台的私有协议。

真实学生花名册、生成过的含姓名 PDF、扫描件和 SQLite 数据库均不应打进源码包。

## 启动

要求 Python 3.9+。在项目根目录执行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/pip install -e '.[dev]'
.venv/bin/homeworkflow
```

程序只监听 `127.0.0.1`，启动后自动打开浏览器。Windows 激活虚拟环境后也可以执行：

```powershell
python -m homeworkflow.main
```

## 测试

```bash
.venv/bin/pytest
```

测试包含从签发 PDF、反向扫描、SQLite 入库、批次确认到 Excel 导出的完整流程。

## 学生名单格式

每行一名学生，学号与姓名之间使用空格：

```text
01 张三
02 李四
```

中间可以是一个或多个空格，也可以直接从 Excel 的“学号、姓名”两列复制粘贴，浏览器会保留两列之间的 Tab。旧版 XLSX/CSV 解析接口仍在后端保留，以兼容已有调用。

## 隐私

项目默认忽略 `.xlsx`、`.xls`、`.pdf`、`.zip` 和 `var/` 运行数据。开发时请不要把真实学生名单、扫描件、数据库或导出结果提交到公开仓库。

架构和后续增强建议见 [DEVELOPMENT.md](DEVELOPMENT.md)。
